# Rafeeq · رفيق

An Arabic AI companion for elderly people, and a care-coordination app for their families and caregivers. Saudi Arabia and the GCC first.

> Rafeeq is a companion and care-coordination tool. It is **not** a medical device and does not give medical advice.

| Folder | What |
|---|---|
| [`backend/`](backend/) | .NET 9 modular backend (family circles, care plans, check-ins, alerts, notifications, caregivers) |
| [`mobile/`](mobile/) | Flutter app with a parent mode and a family mode |
| [`ai-service/`](ai-service/) | Python AI service: Arabic voice companion, safety layer |
| [`frontend/`](frontend/) | Angular + Nx web apps (later phase) |
| [`docs/`](docs/) | Requirements, safety rules, brand kit, architecture |

Contributor and AI-assistant rules: [`CLAUDE.md`](CLAUDE.md) and the `CLAUDE.md` in each folder.
